# Home Tutor Finder

A Django-based Home Tutor Finder platform that helps students find qualified tutors based on class, subject, location, availability, fee, and ratings.

## Features

- Student registration and login
- Tutor registration and login
- Forgot password / password reset
- Student profile
- Tutor profile
- Class 2 to Class 10
- Subject-based tutor search
- GPS-based location
- Nearby tutor search
- Tutor search, filter and sorting
- Tutor request system
- Accept / Reject tutor requests
- Student, Tutor and Admin notifications
- Unread notification count
- Reviews and ratings
- Tutor verification
- Admin dashboard
- Django Admin panel

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript
- Bootstrap
